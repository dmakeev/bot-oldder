# План работ: Telegram-бот «PROсрочка» (Часть 1)

## 1. Общее описание

Бот-помощник для юриста по банкротству: расчёт и напоминание о процессуальных сроках, ведение справочника, работа с делами о банкротстве и арбитражными спорами.

**Стек:** Python 3.10+, python-telegram-bot v20+ (с JobQueue), SQLite для хранения, APScheduler для планирования.

**Основные принципы:**
- Сроки считает программа по справочнику (отдельный файл данных), не ИИ
- Справочник легко обновлять без перезапуска бота
- Персистентность данных между перезапусками
- Раздельное хранилище для каждого чата (личка/группа)

## 5. Ключевые решения по архитектуре

### 5.1. Хранение данных

**SQLite** с асинхронным драйвером (aiosqlite). Причины:
- Простота настройки, не требует отдельного сервера
- Хорошая производительность для небольшого объёма данных
- Поддержка транзакций и ACID
- Легко бэкапить (один файл)

**Структура таблиц:**
- `chats`: chat_id, type (private/group), name
- `projects`: id, chat_id, name, case_number, type, procedures, created_at, active
- `events`: id, project_id, type, scheduled_at, status, data (JSON)
- `reminders`: id, event_id, scheduled_at, status, is_done, is_cancelled
- `user_access`: chat_id, user_id, status, approved_by, approved_at

### 5.2. Расчёт дат

Отдельный модуль `date_calc.py` с функциями:
- `add_days(date, days, workdays=False)` - добавить дни
- `is_workday(date, year)` - проверка рабочего дня
- `get_reminder_dates(deadline, days_before)` - расчёт дат напоминаний
- `format_deadline(deadline, workday_info)` - форматирование для вывода

### 5.3. Справочник сроков

Отдельный JSON-файл `reference.json` со структурой:
```json
{
  "version": "4",
  "date": "2026-10-28",
  "items": [
    {
      "id": "1.1",
      "action": "Провести собрание кредиторов",
      "deadline": "1 раз в 3 месяца",
      "from": "введение процедуры или дата прошлого СК",
      "law": "Вы; для КП: п. 1 ст. 143 ЗоБ",
      "mode": "reminder_repeat",
      "reminders": ["immediate", "-6w", "-3w", "-16d", "-16d", "-7d", "-3d", "-1d"]
    }
  ]
}
```

### 5.4. Обработка сообщений

Использование `ConversationHandler` для пошагового создания проектов:
1. Выбор типа проекта
2. Ввод названия
3. Ввод номера дела
4. Выбор процедуры
5. Ввод даты введения процедуры
